Bubbly 1.0.0

  • Bubbly의 첫 정식 판입니다. macOS 알림을 원하는 자리에, 원하는 모양으로 띄웁니다.
  • 무료: 카드 방식(화면의 아홉 자리 · 여러 모니터), 테마 3종(Glass · Minimal Pill · Classic), 답장 · 히스토리 · 앱별 규칙 · 조용한 모드. 알림 수 제한은 없습니다.
  • Pro(한 번 결제): 노치 · Dock 말풍선 · 캐릭터 방식과 테마 7종이 더해집니다. 키 하나로 Mac 3대, 1.x 업데이트는 무료입니다.

English

  • The first official release of Bubbly. Show macOS notifications where you want them, the way you want them.
  • Free: Card style (nine spots, multiple displays), 3 themes (Glass · Minimal Pill · Classic), replies, history, per-app rules and Quiet mode. No limit on notifications.
  • Pro (one-time purchase): adds the Notch, Dock bubble and Character styles and 7 more themes. One key for 3 Macs, free 1.x updates.
